Each time you start something new, it gets a title in History, in your own words, and when the work changes, so does its title. When you quote a message, cx reads it with the ones around it before it answers.

## What it costs

Jev tells whether a message starts something new, paid from your balance or with your own TypeSafe API key. The model you chat on writes the titles, billed as your chat is.

## What it needs

It needs Jev, which Plugins installs with it.
